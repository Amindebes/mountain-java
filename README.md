# Mountain Java

A Java object-oriented programming project that models a mountain using a custom Mountain class.

## Overview

This project demonstrates basic object-oriented programming concepts in Java by creating a Mountain class with information about a mountain's name, continent, and elevation.

The class uses private instance variables and provides a constructor, setters, getters, validation, and a toString method.

## Concepts Demonstrated

- Java
- Object-oriented programming
- Classes and objects
- Encapsulation
- Private instance variables
- Constructors
- Getters and setters
- Input validation
- Methods
- String formatting

## How It Works

The Mountain class stores three pieces of information:

- Mountain name
- Continent
- Elevation in feet

A constructor is used to initialize the mountain's information. Setter methods allow the values to be changed, while getter methods return the stored information.

The elevation setter also validates the value and prevents negative or zero elevations from being stored.

The toString method returns a formatted description of the mountain.

## Example

A Mountain object can contain information such as:

Name: Mount Everest
Continent: Asia
Elevation: 29032 feet

The program can then return a description such as:

Mount Everest is the highest mountain in Asia at 29032 feet.

## Compilation

Compile the program using:

javac Mountain.java

## Running

Run the compiled program using:

java Mountain
